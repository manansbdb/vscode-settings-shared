# VS Code Settings Shared / Definições VS Code partilhadas

## Overview / Visão geral

**EN:** Shared `settings.json` and `extensions.json` recommendations for teams.

**PT:** `settings.json` e `extensions.json` partilhados para equipas.

## Files / Ficheiros

| File | EN | PT |
|------|----|----|
| `.vscode/settings.json` | Workspace settings | Definições do workspace |
| `.vscode/extensions.json` | Extension recommendations | Extensões recomendadas |

## Usage / Uso

**EN:** Copy `.vscode/` into your project root.

**PT:** Copia `.vscode/` para a raiz do projeto.
